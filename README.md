# Libre HW Tab

Нативная приборная панель для Android-планшета и автономный агент Windows x64 на LibreHardwareMonitor. Без браузера, облака и платной подписки.

## Установка

Готовые **LibreHwTab.apk** и **LibreHwTab-Windows-x64.zip** находятся в [Releases](https://github.com/AlexSapronov/libre_hw_tab/releases). GitHub Actions собирает их из исходников. Preview APK подписан отладочным ключом; при обновлении между сборками может потребоваться удаление старого APK.

1. На Windows 10/11 x64 распакуй ZIP в обычную папку (не запускай установщик прямо внутри архива). Запусти **Install.cmd**, подтверди запрос администратора. .NET и отдельная программа LibreHardwareMonitor не нужны.
2. Установщик выведет IP-адрес и ключ. Для температур CPU и ряда низкоуровневых датчиков LibreHardwareMonitor 0.9.6 использует **PawnIO**: установи официальный драйвер с [pawnio.eu](https://pawnio.eu/) и перезагрузи ПК, если температура CPU отсутствует. Администраторские права сами по себе драйвер не заменяют.
3. Домашняя сеть Windows должна иметь профиль **Частная**. Установщик добавляет правило брандмауэра только для частной сети и локальной подсети.
4. На ПК установщик автоматически откроет окно с QR. Повторно его можно открыть через **Pair.cmd** из распакованного архива. На планшете установи APK, открой **ПОДКЛЮЧЕНИЕ → Сканировать QR**, разреши камеру и наведи её на код. Адрес и ключ сохранятся автоматически только после проверки соединения. Если у ПК несколько сетевых адресов, планшет переберёт их сам; в окне ПК также можно выбрать конкретный адрес. Ручной ввод оставлен как запасной вариант. Оба устройства должны быть в одной LAN; гостевая Wi-Fi-сеть с изоляцией клиентов не подходит.
5. Планшет запоминает подключение, работает в альбомной ориентации, скрывает системные панели и не гасит экран, пока приложение открыто. **THEME** переключает Jade / EVA. **ПОДКЛЮЧЕНИЕ → Демо** показывает явно подписанные тестовые данные; «Подключить» возвращает реальные датчики.

Для постоянной работы зарезервируй IP компьютера в настройках DHCP роутера. Агент запускается через планировщик при входе пользователя в Windows, с повышенными правами. На планшете приложение открывается вручную; автозапуск Android после перезагрузки в эту версию не входит.

**Удаление Windows:** запусти `Uninstall.ps1` через PowerShell; он уберёт задачу, правило брандмауэра и установленные бинарники. Ключ останется в `%LOCALAPPDATA%\LibreHwTab\connection.json`. Для полного сброса удали и эту папку после удаления агента.

## Экран

- CPU / GPU: температура, загрузка, частота, мощность и обороты вентилятора.
- RAM: фактически используемый объём, общий объём и процент.
- История температур CPU / GPU: последние 180 попыток опроса (примерно 3 минуты при исправной связи), с разрывами при потере связи.
- Темы: Jade (мята + янтарь), EVA (зелёный + фиолетовый).
- Датчики и названия оборудования определяются на ПК. Недоступное значение — `—`. При потере соединения старые показания сразу скрываются, опрос повторяется автоматически.
- Температурный акцент предупреждения: CPU от 85 °C, GPU от 83 °C. Это визуальные ориентиры, не паспортные пределы конкретного чипа.

Приложение рисует интерфейс непосредственно Android Canvas, без WebView и сетевых шрифтов. Минимум Android 8.0 (API 26), универсальный APK без привязки к архитектуре процессора. Макет масштабируется целиком под альбомный экран, сохраняя пропорции. Проверка непосредственно на Tab A11 SM-X130 и реальных датчиках ПК необходима.

FPS / 1% low не показаны: LibreHardwareMonitor не является источником кадровой статистики игр. GPU load — процент загрузки, а не FPS. Для FPS нужен отдельный источник (например, PresentMon) и последующая интеграция.

## Соединение и безопасность

Агент слушает TCP 8750, только `GET /api/v1/telemetry`. Требует заголовок `X-Libre-Token`, ключ — случайные 128 бит. Интерфейс управления ПК отсутствует. Ключ хранится в локальном профиле пользователя и закрытых настройках приложения; не публикуй `connection.json`.

По умолчанию транспорт — **HTTP в доверенной домашней сети**, без шифрования. Не пробрасывай порт на роутере и не используй публичный Wi-Fi. Правило установщика ограничивает доступ локальной подсетью в частном профиле. Для внешнего доступа нужен VPN. Агент не поддерживает HTTPS самостоятельно.

При ошибке чтения датчиков API отдаёт пустые показания и сообщение, а не старые значения. Планшет проверяет версию схемы, свежесть времени (10 с), ограничивает ответ 64 КиБ, не следует редиректам с ключом. Часы ПК и планшета должны быть синхронизированы.

## Сборка

- Android: JDK 17, Android SDK 35, Gradle 8.11.1; `cd android` → `gradle :app:assembleDebug :app:lintDebug`.
- Windows: .NET SDK 10; `dotnet publish agent/LibreHwAgent.csproj -c Release -o package/agent`.
- `.github/workflows/build.yml` проверяет lint, компилирует обе части, публикует ZIP и установочный preview APK только после успеха обеих сборок.

Схема API — `docs/telemetry.example.json`. CPU-датчик выбирает Tctl/Tdie или CPU Package, GPU предпочитает NVIDIA → AMD → Intel; для нескольких дискретных GPU пока используется первый подходящий. Частота CPU — максимум доступных частот ядер, RAM объём — датчики Data физического блока `/ram` (Total Memory), виртуальная память `/vram` и DIMM-датчики в этот расчёт не входят. Некоторые датчики зависят от модели железа и драйверов.

## QR-подключение

QR создаётся локально и содержит версию формата, список частных IPv4-адресов ПК и ключ. Сторонние QR, публичные адреса, редиректы, адреса с логином, путём или параметрами не принимаются. Никакие сайты для генерации QR не используются. Сканер встроен в APK, отдельное приложение не нужно; без доступа к камере остаётся ручной ввод. Не публикуй фото QR — он содержит ключ доступа. При отмене или неудачной проверке старое подключение сохраняется.

Версия 1.1 использует постоянный публичный ключ подписи preview-сборок для установки следующих обновлений поверх. При переходе с первой версии 1.0 APK нужно один раз удалить старое приложение (его прежний временный ключ подписи восстановить нельзя), затем установить новую версию. Это ключ для тестовых сборок, не для магазина приложений.

## Физическая RAM и охлаждение (1.2)

В версии 1.2 исправлен выбор памяти: в LibreHardwareMonitor 0.9.6 первым перечисляется Virtual Memory (RAM + файл подкачки). Теперь объём, занятое место и процент берутся только из физического блока Total Memory (`/ram`). При недоступном блоке показания скрываются, а виртуальная память не подставляется.

Включено чтение материнской платы и её вложенных SuperIO/EC-датчиков. По подтверждённым снимкам LibreHardwareMonitor и Fan Control для **ASUS TUF GAMING B650M-PLUS / Nuvoton NCT6799D** используется профиль: **Fan #1 → верх/AIO, Fan #2 → бок/вдув, Fan #7 → помпа**. Привязка отражает проводку этого рабочего места; на других платах номера каналов автоматически не угадываются. Данные GPU в этот выбор не попадают. На других платах допускаются только явно именованные CPU Fan/AIO Pump; неизвестный канал остаётся пустым. В API `cooling.fans` публикуются идентификаторы, исходные названия, плата и текущие RPM для диагностики.

Агент только читает обороты, не вызывает управление PWM/режимами и не меняет кривые Fan Control. На завершении процесса не вызывается `Computer.Close()`: в LibreHardwareMonitor 0.9.6 этот метод сбрасывает SuperIO-управление даже при использовании только чтения. Ресурсы освобождает Windows при завершении процесса агента.

В Android выведены верх/AIO, бок и помпа раздельно; цифры и подпись LOAD центрируются относительно середины дуги и метрик шрифта. Новое APK 1.2 устанавливается поверх 1.1 с сохранением подключения (постоянный preview-ключ).
