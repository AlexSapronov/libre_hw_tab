# Libre HW Tab

Нативная приборная панель для Android-планшета и автономный агент Windows x64 на LibreHardwareMonitor. Без браузера, облака и платной подписки.

## Установка

Готовые **LibreHwTab.apk** и **LibreHwTab-Windows-x64.zip** находятся в [Releases](https://github.com/AlexSapronov/libre_hw_tab/releases). GitHub Actions собирает их из исходников. Preview APK подписан отладочным ключом; при обновлении между сборками может потребоваться удаление старого APK.

1. На Windows 10/11 x64 распакуй ZIP в обычную папку (не запускай установщик прямо внутри архива). Запусти **Install.cmd**, подтверди запрос администратора. .NET и отдельная программа LibreHardwareMonitor не нужны.
2. Установщик выведет IP-адрес и ключ. Для температур CPU и ряда низкоуровневых датчиков LibreHardwareMonitor 0.9.6 использует **PawnIO**: установи официальный драйвер с [pawnio.eu](https://pawnio.eu/) и перезагрузи ПК, если температура CPU отсутствует. Администраторские права сами по себе драйвер не заменяют.
3. Домашняя сеть Windows должна иметь профиль **Частная**. Установщик добавляет правило брандмауэра только для частной сети и локальной подсети.
4. На ПК установщик автоматически откроет окно с QR. Повторно его можно открыть через **Pair.cmd** из распакованного архива. На планшете установи APK, открой **ПОДКЛЮЧЕНИЕ → Сканировать QR**, разреши камеру и наведи её на код. Адрес и ключ сохранятся автоматически только после проверки соединения. Если у ПК несколько сетевых адресов, планшет переберёт их сам; в окне ПК также можно выбрать конкретный адрес. Ручной ввод оставлен как запасной вариант. Оба устройства должны быть в одной LAN; гостевая Wi-Fi-сеть с изоляцией клиентов не подходит.
5. Планшет запоминает подключение, работает в альбомной ориентации, скрывает системные панели и не гасит экран, пока приложение открыто. **THEME** переключает Jade / EVA. **ПОДКЛЮЧЕНИЕ → Демо** показывает явно подписанные тестовые данные; «Подключить» возвращает реальные датчики.

Для постоянной работы зарезервируй IP компьютера в настройках DHCP роутера. Агент запускается через планировщик при входе пользователя в Windows, с повышенными правами. На планшете приложение открывается вручную; автозапуск Android после перезагрузки в эту версию не входит.

**Удаление Windows:** запусти `Uninstall.ps1` через PowerShell; он уберёт задачу, правило брандмауэра и установленные бинарники. Ключ останется в `%LOCALAPPDATA%\LibreHwTab\connection.json`. Для полного сброса удали и эту папку после удаления агента.

## Экран

- CPU / GPU: температура, загрузка, частота, мощность и обороты вентилятора.
- RAM: фактически используемый объём, общий объём и процент.
- История температур CPU / GPU: последние 180 попыток опроса (примерно 3 минуты при исправной связи), с разрывами при потере связи.
- Темы: Jade (мята + янтарь), EVA (зелёный + фиолетовый).
- Датчики и названия оборудования определяются на ПК. Недоступное значение — `—`. При потере соединения старые показания сразу скрываются, опрос повторяется автоматически.
- Температурный акцент предупреждения: CPU от 85 °C, GPU от 83 °C. Это визуальные ориентиры, не паспортные пределы конкретного чипа.

Приложение рисует интерфейс непосредственно Android Canvas, без WebView и сетевых шрифтов. Минимум Android 8.0 (API 26), универсальный APK без привязки к архитектуре процессора. Макет масштабируется целиком под альбомный экран, сохраняя пропорции. Проверка непосредственно на Tab A11 SM-X130 и реальных датчиках ПК необходима.

FPS / 1% low и время кадра доступны в игровом режиме версии 1.4 через отдельный встроенный сборщик PresentMon; GPU load остаётся процентом загрузки.

## Соединение и безопасность

Агент слушает TCP 8750, только `GET /api/v1/telemetry`. Требует заголовок `X-Libre-Token`, ключ — случайные 128 бит. Интерфейс управления ПК отсутствует. Ключ хранится в локальном профиле пользователя и закрытых настройках приложения; не публикуй `connection.json`.

По умолчанию транспорт — **HTTP в доверенной домашней сети**, без шифрования. Не пробрасывай порт на роутере и не используй публичный Wi-Fi. Правило установщика ограничивает доступ локальной подсетью в частном профиле. Для внешнего доступа нужен VPN. Агент не поддерживает HTTPS самостоятельно.

При ошибке чтения датчиков API отдаёт пустые показания и сообщение, а не старые значения. Планшет проверяет версию схемы, свежесть времени (10 с), ограничивает ответ 64 КиБ, не следует редиректам с ключом. Часы ПК и планшета должны быть синхронизированы.

## Сборка

- Android: JDK 17, Android SDK 35, Gradle 8.11.1; `cd android` → `gradle :app:assembleDebug :app:lintDebug`.
- Windows: .NET SDK 10; `dotnet publish agent/LibreHwAgent.csproj -c Release -o package/agent`.
- `.github/workflows/build.yml` проверяет lint, компилирует обе части, публикует ZIP и установочный preview APK только после успеха обеих сборок.

Схема API — `docs/telemetry.example.json`. CPU-датчик выбирает Tctl/Tdie или CPU Package, GPU предпочитает NVIDIA → AMD → Intel; для нескольких дискретных GPU пока используется первый подходящий. Частота CPU — максимум доступных частот ядер, RAM объём — датчики Data физического блока `/ram` (Total Memory), виртуальная память `/vram` и DIMM-датчики в этот расчёт не входят. Некоторые датчики зависят от модели железа и драйверов.

## QR-подключение

QR создаётся локально и содержит версию формата, список частных IPv4-адресов ПК и ключ. Сторонние QR, публичные адреса, редиректы, адреса с логином, путём или параметрами не принимаются. Никакие сайты для генерации QR не используются. Сканер встроен в APK, отдельное приложение не нужно; без доступа к камере остаётся ручной ввод. Не публикуй фото QR — он содержит ключ доступа. При отмене или неудачной проверке старое подключение сохраняется.

Версия 1.1 использует постоянный публичный ключ подписи preview-сборок для установки следующих обновлений поверх. При переходе с первой версии 1.0 APK нужно один раз удалить старое приложение (его прежний временный ключ подписи восстановить нельзя), затем установить новую версию. Это ключ для тестовых сборок, не для магазина приложений.

## Физическая RAM и охлаждение (1.2)

В версии 1.2 исправлен выбор памяти: в LibreHardwareMonitor 0.9.6 первым перечисляется Virtual Memory (RAM + файл подкачки). Занятое место и процент берутся только из физического блока Total Memory (`/ram`). Общая установленная ёмкость DIMM получается из Windows `GetPhysicallyInstalledSystemMemory`; при недоступности этого API используется физический объём LHM. Доступный ОС объём (после аппаратного резерва, в том числе iGPU) отдельно публикуется как `memory.usableTotal`; процент загрузки относится к нему. При недоступном блоке показания скрываются, а виртуальная память не подставляется.

Включено чтение материнской платы и её вложенных SuperIO/EC-датчиков. По подтверждённым снимкам LibreHardwareMonitor и Fan Control для **ASUS TUF GAMING B650M-PLUS / Nuvoton NCT6799D** используется профиль: **Fan #1 → верх/AIO, Fan #2 → бок/вдув, Fan #7 → помпа**. Привязка отражает проводку этого рабочего места; на других платах номера каналов автоматически не угадываются. Данные GPU в этот выбор не попадают. На других платах допускаются только явно именованные CPU Fan/AIO Pump; неизвестный канал остаётся пустым. В API `cooling.fans` публикуются идентификаторы, исходные названия, плата и текущие RPM для диагностики.

Агент только читает обороты, не вызывает управление PWM/режимами и не меняет кривые Fan Control. На завершении процесса не вызывается `Computer.Close()`: в LibreHardwareMonitor 0.9.6 этот метод сбрасывает SuperIO-управление даже при использовании только чтения. Ресурсы освобождает Windows при завершении процесса агента.

В Android выведены верх/AIO, бок и помпа раздельно; цифры и подпись LOAD центрируются относительно середины дуги и метрик шрифта. Новое APK 1.2 устанавливается поверх 1.1 с сохранением подключения (постоянный preview-ключ).

## Отдельный блок охлаждения (1.3)

Справа расположен высокий блок COOLING с четырьмя каналами: верх/AIO, бок/вдув, помпа и вентилятор GPU. У каждого канала отдельно показаны RPM и источник. Карточки CPU/GPU содержат температуру, загрузку, частоту и мощность; ниже остаются RAM и история температур. Изменение требует только обновления APK поверх 1.2; агент Windows версии 1.2 совместим, подключение сохраняется.

## Автоматический игровой экран (1.4)

Windows-пакет включает официальный **PresentMon 2.6.0 x64 standalone**, закреплённый SHA-256. Отдельная установка PresentMon/MSI, RTSS, CapFrameX и оверлей не нужны. Агент запускает сборщик скрыто, читает CSV напрямую из stdout и не пишет покадровые журналы на диск. Работает с повышенными правами через существующую задачу автозапуска. Сбой FPS-сборщика не отключает температуры/обороты; внизу экрана появляется статус источника, сборщик перезапускается через 15 секунд.

Автоматическое переключение требует активного окна подходящей игры, потока кадров не ниже 10 FPS и непрерывного подтверждения **3 секунды**. WoW/WoWClassic и ZenlessZoneZero распознаются по EXE даже в оконном режиме. Другие приложения определяются по папкам Steam/Epic/Games/HoYoPlay либо окну, занимающему не менее 80% ширины и высоты монитора. Браузеры, популярные видеоплееры, лаунчеры, Discord, OBS, Blender и редакторы исключены. Это эвристика, а не универсальная база всех игр.

Короткий Alt+Tab сохраняет игровой экран до **10 секунд**, скрывая устаревшие FPS/график. При закрытии игрового процесса экран возвращается к обзору; при долгой потере фокуса — тоже. Игра снова включается при возврате и подтверждённой кадровой активности. Без новых кадров более двух секунд значения скрываются. Во время загрузок возможна задержка переключения — фальшивые FPS не подставляются.

Кнопка вверху переключает **AUTO → ОБЗОР → ИГРА**. Выбор сохраняется на планшете. Для нестандартного EXE можно добавить его в `%LOCALAPPDATA%\LibreHwTab\games.json` (изменения подхватываются за секунду):

```json
{"Include": ["customgame.exe"], "Exclude": ["benchmark.exe"]}
```

Измерения: **Presented FPS = 1000 / среднее MsBetweenPresents за последнюю секунду**; время кадра — то же среднее в мс. Это поток вызовов Present приложения, а не гарантированное число показанных на экране кадров после Frame Generation. Отдельный счётчик FG/displayed FPS в 1.4 не реализован. **1% low** = 1000 / среднее худшего 1% интервалов за последние 10 с (доступен после 60 кадров и минимум секунды данных). В версии 1.5 график содержит последние 60 секунд: 300 временных корзин по 200 мс, каждая показывает максимальный frametime в интервале. Ось времени фиксирована и не зависит от FPS; пустые интервалы остаются разрывами. Выбирается основной swapchain процесса по наибольшему числу кадров за секунду, потоки разных процессов/swapchain не складываются. История ограничена 32 каналами и 16384 кадрами на канал; неактивные каналы очищаются.

Информация об активном окне используется локально для выбора процесса. На планшет отправляется только выбранная игра (заголовок/имя, PID, кадровые показатели), а не список запущенных процессов или полные пути. Поддержка конкретных игр, античитов и графических API зависит от PresentMon; при недоступных событиях FPS остаётся пустым. Нужна проверка на реальных WoW и ZZZ после установки.

Обновление: распаковать новый Windows ZIP → Install.cmd, на планшете установить APK 1.4 поверх 1.1–1.3. Адрес/ключ и тема сохраняются. При завершении/сбое агента Windows Job Object завершает только его дочерний PresentMon. Именованная ETW-сессия сборщика изолирована как LibreHwTab-<WindowsSessionId>; сессии других мониторов не останавливаются.

Установщик/удаление также явно останавливают только сессию LibreHwTab текущего сеанса Windows после завершения агента; это очищает сессию даже после принудительной остановки процесса. При штатной остановке то же делает агент.

### Игровая боковая панель (1.4.1)

В игровом режиме справа отображаются отдельные секции GPU и CPU: крупная температура, процент загрузки и полоса загрузки. Обороты остаются в правой панели только обычного обзора. Строка CPU/GPU под FPS убрана; все аппаратные показатели игрового экрана сгруппированы справа. Для изменения достаточно обновить APK поверх 1.4, Windows-агент не меняется.

## Обновление 1.5

История frametime — 60 секунд с пиками по 200 мс (300 точек). Сырые кадры последних 10 секунд отдельно используются для FPS/1% low; изменения графика не меняют статистику. Старое поле API frames сохранено для старых клиентов, новый график использует frameSeries. График температур в обзоре привязан к реальным 180 секундам, а не числу сетевых запросов.

Планшет опрашивает API каждые 200 мс одним последовательным исполнителем, пропуская просроченные слоты без всплеска запросов. Агент обновляет игровые показатели и CPU/GPU/физическую RAM с целевым интервалом 200 мс; операции не перекрываются. Чтение материнской платы/оборотов, метаданных окна и правил игр остаётся раз в секунду, чтобы не нагружать SuperIO/SMBus. Реальная задержка зависит от сети, датчиков и ETW; 200 мс — период опроса, а не гарантия полной задержки от кадра до экрана.

Темы: Jade, EVA, Arctic, Sakura, Amber, Crimson. Меняются акценты, фон и панели; выбор сохраняется, старая настройка EVA мигрирует автоматически. Убраны справочные строки снизу и внутри карточек; сообщения реальных ошибок остаются. RPM/°C следуют за шириной числа с отступом 10 единиц макета. Игровой график увеличен по высоте. Для новой истории и частоты требуется обновить Windows-пакет и APK; подключение сохраняется.

## 1.6 — ожидание, редактор, NERV и Wake-on-LAN

Обновление UI и игровых показателей — **500 мс**, график остаётся 60-секундным с корзинами пиков по 200 мс. Добавлен 0,1% low: 1000 / среднее худших ceil(N × 0,001) покадровых интервалов за последние 60 секунд, минимум 1000 кадров и 10 секунд сбора, лимит 65536 кадров на канал. Показатель не подставляется из 1% low.

**Ожидание:** после 15 секунд без валидных данных ПК отображаются часы, дата, погода и ближайший системный будильник; успешное подключение автоматически возвращает панель. Это обнаружение недоступности ПК, а не доказательство выключенного питания. Ручной вход — МЕНЮ → Экран ожидания; кнопка ПАНЕЛЬ возвращает обзор. Погода по умолчанию Санкт-Петербург, другой город выбирается поиском с уточнением региона/страны. HTTPS Open-Meteo без ключа, резервный сервис wttr.in при ошибке. Обновление каждые 15 минут при открытом приложении, при сбое повтор через 30 секунд. Нажатие на погоду открывает ручное обновление, выбор города и причины ошибок обоих сервисов. Сохранённые данные помечаются при возрасте от 15 минут. Не требуется геолокация; отправляются координаты выбранного города. Без интернета часы и будильник работают, свежая погода недоступна. Данные: https://open-meteo.com/ и https://wttr.in/ (поставщик указан на экране).

**Будильник:** кнопка на экране ожидания открывает выбор времени и передаёт его системному приложению Часы через ACTION_SET_ALARM. Подтверди параметры в Часах; повторение/звук/удаление настраиваются там. Ближайший будильник берётся из AlarmManager.getNextAlarmClock. Он принадлежит системным Часам, поэтому не зависит от ПК и жизни нашего процесса. Если приложения Часы нет, интерфейс явно сообщает об этом; наше приложение не имитирует успешное создание.

**Редактор:** МЕНЮ → Редактор блоков → Обзор/Игра. Перетаскивай карточки, изменяй размер за нижний правый угол. БЛОКИ / ДАННЫЕ позволяет скрыть карточки и показатели. Шаг перемещения 10 единиц макета; размеры ограничены экраном, пересечения подсвечены красным и не сохраняются. СОХРАНИТЬ сохраняет отдельный макет режима, ОТМЕНА восстанавливает прежний. Содержимое масштабируется пропорционально без растягивания шрифта. Сброс обоих макетов доступен в редакторе.

**NERV:** седьмая тема — угловые панели, моноширинная типографика, красно-оранжевая палитра, сигнальные полосы и короткий 450-мс проход скан-линии при смене режима/темы. Анимации можно отключить через меню. Постоянной фоновой анимации нет.

**Wake-on-LAN:** обновлённый агент отдаёт MAC и широковещательные адреса активных Ethernet/Wi-Fi-адаптеров через авторизованный API; планшет сохраняет их. В ожидании нажми ВКЛЮЧИТЬ / РАЗБУДИТЬ ПК. Отправляется стандартный magic packet UDP/9 только в домашнюю сеть. Подтверждение — фактическое восстановление API, а не успешная отправка UDP. Ручной MAC доступен в МЕНЮ → Wake-on-LAN. Нужны разрешённые Wake-on-LAN/PCIe wake в BIOS и пробуждение Magic Packet у адаптера; надёжнее Ethernet. Выход из сна/гибернации/полного выключения зависит от платы, состояния питания, драйвера и Windows; Fast Startup может влиять на выключение. При отключённом питании не сработает. Проброс порта наружу не требуется и функцией не используется. Wi-Fi планшета должен быть без изоляции клиентов.

Для 1.6 обнови Windows-пакет (Install.cmd) и APK поверх текущей версии; ключ/подключение/темы сохраняются. Настройки ожидания/макетов хранятся на планшете.

Обновление 0,1% low требует установки нового Windows-пакета через `Install.cmd`, одного обновления APK недостаточно. Под значением показывается прогресс накопления (1000 кадров и 10 секунд) или просьба обновить агент, если он не передаёт это поле.

Прогноз на завтра на экране ожидания: 09:00 / 15:00 / 21:00 по времени города, температура, состояние, вероятность и количество осадков. Open-Meteo: осадки за час, wttr.in: за трёхчасовой интервал; единицы подписаны. Для wttr.in вероятность — максимум отдельных вероятностей дождя и снега, не их сумма. Прогноз кэшируется вместе с текущей погодой; дата всегда указана, устаревшая дата не называется «завтра». Отсутствующие значения показаны прочерком. Для этой функции достаточно обновить APK.
